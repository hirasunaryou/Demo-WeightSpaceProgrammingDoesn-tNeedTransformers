Mac・Windowsで起動。追加pip、GPU、venv不要。収録した原著の一部知識行を、独立した教材用スコア計算で観察・編集。

公開モデルと評価コード

著者のbuild.pyが重みを作り、arch.pyがPyTorchで読み出す。ARC 3,530問の精度・GPU速度は原著の測定値で、このデモでは再計測していません。

必要な実行環境

項目原著READMEの説明
OS一連の実験管理はLinuxで、bubblewrap（bwrap 0.6.3）が使われています。
PythonPython 3.11（著者の使用例3.11.13）、公式requirements.txtで依存関係を固定。
ライブラリPyTorch、NumPy、Hugging Face関連パッケージなど。モデルによって別venvが必要。
GPU公開テキストのARCモデル評価はCPUで行える部分があります。一部のリリース済みLM編集やベースラインはCUDA GPUが必要。
データARC（AI2 Reasoning Challenge）を事前取得。データのライセンスはCC BY-SA 4.0。
LLM Writer新しいモデルの作成・lineage実験は商用LLMとCLI認証を用います。公開済みモデルの閲覧・教材体験にWriterは不要です。

原著のモデルを再評価する場合

正確な準備と依存関係は、固定した公式READMEを優先してください。以下は原著のコマンドに沿った見取り図です。このページで実行した・成功を検証したコマンドではありません。

git clone https://github.com/effl-lab/Weight-Space-Programming.git
cd Weight-Space-Programming
git checkout c3324efa7e8aeec9ff7b7303094799b67a20793b

# Linuxのvenv等に公式依存関係をセットアップ
python -m pip install -r requirements.txt

# ARCデータをHugging Faceから事前にダウンロード
huggingface-cli download allenai/ai2_arc --repo-type dataset

export WSP_DATA_ROOT=/path/to/wsp_data
export HF_HOME=/path/to/hf_cache

# 著者のscore_modelはLinux bwrap環境を前提とします
python -m harness.score_model \
  models/opus/mem_assoc2_g5-arc_blind_K0_r0
実験費用と再現性：Writerエージェントを新しく動かす場合はAPI課金・CLI設定が必要になる可能性があります。自動的にWriterは起動しないでください。また、異なるCPUでは浮動小数点演算順序により0.数ポイント程度の変動が生じ得ることを著者は説明しています。
